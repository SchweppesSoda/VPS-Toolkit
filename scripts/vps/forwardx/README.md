# ForwardX NAT Agent Adapter

`forwardx-nat-agent-adapter.sh` wraps the ForwardX agent install command for
NAT VPS hosts, especially Alpine/BusyBox systems without systemd.

Provider NAT mapping is still configured in the provider panel. This script only
records the mapping locally and keeps the ForwardX agent alive.

Example:

```bash
tmp="$(mktemp)"
curl -fsSL https://raw.githubusercontent.com/SchweppesSoda/VPS-Toolkit/main/scripts/vps/forwardx/forwardx-nat-agent-adapter.sh -o "$tmp"
sudo bash "$tmp" install --public-port 54999 --internal-port 81 --proto both
rm -f "$tmp"
```

Then paste the ForwardX agent install command generated by the ForwardX panel.

Important rule:

```text
Provider panel: public 54999 -> VPS internal 81
ForwardX panel: listen/entry port = 81
External users: provider public IP:54999
```

Use `curl | bash` only for non-interactive runs where the ForwardX install
command is already saved in a root-only file and passed with `--command-file`:

```bash
curl -fsSL https://raw.githubusercontent.com/SchweppesSoda/VPS-Toolkit/main/scripts/vps/forwardx/forwardx-nat-agent-adapter.sh | sudo bash -s -- install \
  --public-port 54999 \
  --internal-port 81 \
  --proto both \
  --command-file /root/forwardx-agent-install.sh
```

Diagnostics:

```bash
curl -fsSL https://raw.githubusercontent.com/SchweppesSoda/VPS-Toolkit/main/scripts/vps/forwardx/forwardx-nat-agent-adapter.sh | sudo bash -s -- diagnose
curl -fsSL https://raw.githubusercontent.com/SchweppesSoda/VPS-Toolkit/main/scripts/vps/forwardx/forwardx-nat-agent-adapter.sh | sudo bash -s -- diagnose --public-port 54999 --internal-port 81
```
