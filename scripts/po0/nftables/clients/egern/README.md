# Egern PO0 防火墙

导入 [PO0-Firewall.yaml](https://raw.githubusercontent.com/SchweppesSoda/VPS-Toolkit/main/scripts/po0/nftables/clients/egern/PO0-Firewall.yaml)，自动上报出口 IP，查询防火墙白名单。

## 配置

在“上报账号”填写 `Token@槽位|名称`，例如 `pgnfw_...@0|手机`，然后运行“PO0 防火墙 · 保存配置”。多账号用换行或分号分隔，同一列表内 Token 不可重复。槽位参数 @0～@9 对应界面 #1～#10；不填则自动分配。实际可用槽位以账号返回额度为准（默认 5 个，最多 10 个）；固定槽位超额时会报错且不写入。已保存的 Token 和槽位优先于同步参数，改账号或槽位须重新保存。

“按网络选择账号”默认关闭。开启后，“上报账号”用于蜂窝，Wi-Fi 使用单独保存的“Wi-Fi 账号”。Wi-Fi 账号留空保留原值，填 - 并保存可清空。间隔、定期开关、网络选择和 Wi-Fi 跳过设置修改后立即生效。

上报间隔默认 600 秒（10 分钟），范围 60～86400 秒。定期上报关闭后仍可在网络变化时检查；“停用自动上报”同时停用这两种自动触发，手动操作仍可用。

“跳过的 Wi-Fi 名称（SSID）”用英文分号分隔，区分大小写；读取不到名称时继续。命中后普通上报和组件刷新不请求，保留上次结果。仅手动“强制上报”可绕过；查询白名单始终只读。

## 操作与显示

- “PO0 防火墙状态”显示账号、出口 IP、槽位、占用和检查时间；运行或刷新时会检查，必要时上报。
- “PO0 防火墙 · 查询白名单”只查询，不修改白名单或推迟下次定期检查。“最近结果”只显示本机缓存。
- “PO0 防火墙 · 清除配置”清除账号、配置及最近结果，并停用自动上报。恢复使用须保存账号，再启用自动上报。
- 更新白名单后会通知；“手动检查成功时通知”开启后，手动命中已有记录也通知。自动检查命中已有记录保持安静。

时间统一显示为“每 10 分钟”“1 分钟 30 秒”，保留秒数；当天显示时分，旧记录补充日期。中文与数字、英文之间保留一个空格，数字与单位之间保留一个空格；不同信息用“ · ”分隔。比例、槽位编号、IP 地址及账号参数内部不插入空格，用户填写的名称保持原样。

结果统一为“已放行”“未放行”“检查失败”。当前出口与白名单记录属于同一 /24 网段时标绿；官方接口只给固定槽位记录编号，自动分配的记录没有编号，组件中显示为“自动”，命中时同样标绿。未知占用不显示为零。记录按 #1～#10 排序，自动记录在最后，命中项不置顶。

组件背景为不透明纯色：浅色模式白色、深色模式深灰，文字与卡片随之切换，与其它组件同样铺满。绿色只表示当前出口已放行及其所在槽位；部分账号未放行用橙色，检查失败用红色，其余信息为中性色。小尺寸最多显示两个账号，中尺寸最多三个，大尺寸最多三个。超过展示上限的账号继续正常后台处理，总览统计全部账号，底部提示未显示的账号数及其中异常；任一账号检查失败时总览标红，部分账号未放行显示橙色，全部已放行才显示绿色。

大尺寸一个账号时，白名单与剩余额度合成一张表：每格显示编号（或“自动”）和对应网段，空闲额度显示为“空闲”，前五格为左列、其余为右列，表格随组件高度伸展。两个或三个账号时每个账号一张卡片：首行显示状态、名称、槽位与占用，出口或检查时间与总览不同时才另行标出；下方两列列出加白网段。两个账号共用五行、三个账号各一行，按记录数分配，放不下时显示“另 N 条”，当前网段的记录始终保留。中尺寸左侧为出口 IP 与网络，右侧为账号卡片：一个账号列出最多三行记录，两个账号显示槽位条，三个账号只显示状态、名称和占用。小尺寸显示出口 IP、网络及每个账号的占用，一个账号时附槽位条。当前网段有编号时，账号摘要显示其槽位，如 #8、#10。

绿色实心为当前网段，灰色填充为其它已占用记录，仅描边为空闲，形状与颜色同时区分。所有记录都有编号时按 #1～#10 原位显示，空闲格带编号；含“自动”记录时先列编号记录、再列自动记录，空闲格不带编号，不猜测位置。额度未知时只列记录，不画空闲格。检查失败时以错误说明替代记录；未知占用保持“占用未知”。完整名单通过只读查询入口查看。时间使用检查时分，旧记录带日期；跳过检查时标明缓存结果。

## 升级与兼容

标准文件为 `PO0-Firewall.yaml` 和 `po0-firewall.js`。本目录及 `scripts/po0/relay/egern/` 的旧文件名仅用于兼容，内容必须与标准文件同步；旧模块更新后同样使用新脚本。更新主配置后刷新模块；已有桌面组件若仍绑定旧名称，重新选择“PO0 防火墙状态”。

本机存储键、账号和槽位保留兼容，旧操作名称仍可识别。首次升级会备份旧配置，清除后同步参数不会自动恢复账号。模块只使用现行防火墙接口，先查询，缺少覆盖才写入；同 /24 网段共用记录，写入被拒绝时仅复查一次。

历史 SSH/自建功能见[固定归档](https://github.com/SchweppesSoda/VPS-Toolkit/releases/tag/archive/po0-full-20260907.1)。专项检查：`node tools/po0/test-egern-official-report.mjs`。项目说明见[PO0 README](../../../relay/README.md)。
