# Egern PO0 防火墙

导入 [PO0-Firewall.yaml](https://raw.githubusercontent.com/SchweppesSoda/VPS-Toolkit/main/scripts/po0/nftables/clients/egern/PO0-Firewall.yaml)，自动上报出口IP，查询防火墙白名单。

## 配置

在“上报账号”填写 `Token@槽位|名称`，例如 `pgnfw_...@0|手机`，然后运行“PO0 防火墙 · 保存配置”。多账号用换行或分号分隔，同一列表内Token不可重复。槽位参数@0～@4对应界面#1～#5；不填则自动分配。已保存的Token和槽位优先于同步参数，改账号或槽位须重新保存。

“按网络选择账号”默认关闭。开启后，“上报账号”用于蜂窝，Wi-Fi使用单独保存的“Wi-Fi账号”。Wi-Fi账号留空保留原值，填-并保存可清空。间隔、定期开关、网络选择和Wi-Fi跳过设置修改后立即生效。

上报间隔默认600秒（10分钟），范围60～86400秒。定期上报关闭后仍可在网络变化时检查；“停用自动上报”同时停用这两种自动触发，手动操作仍可用。

“跳过的Wi-Fi名称（SSID）”用英文分号分隔，区分大小写；读取不到名称时继续。命中后普通上报和组件刷新不请求，保留上次结果。仅手动“强制上报”可绕过；查询白名单始终只读。

## 操作与显示

- “PO0 防火墙状态”显示账号、出口IP、槽位、占用和检查时间；运行或刷新时会检查，必要时上报。
- “PO0 防火墙 · 查询白名单”只查询，不修改白名单或推迟下次定期检查。“最近结果”只显示本机缓存。
- “PO0 防火墙 · 清除配置”清除账号、配置及最近结果，并停用自动上报。恢复使用须保存账号，再启用自动上报。
- 更新白名单后会通知；“手动检查成功时通知”开启后，手动命中已有记录也通知。自动检查命中已有记录保持安静。

时间统一显示为“每10分钟”“1分钟30秒”，保留秒数；当天显示时分，旧记录补充日期。中文与数字、单位之间不加空格，不同信息用“ · ”分隔。用户填写的名称保持原样。

结果统一为“已放行”“未放行”“检查失败”。当前出口与白名单记录属于同一/24网段时标绿；没有返回槽位编号的记录显示“未编号”，命中时同样标绿，账号槽位显示“槽位未知”。未知占用不显示为零。记录按#1～#5排序，未编号记录在最后，命中项不置顶。

小尺寸最多显示两个账号；中尺寸最多三个，单账号显示两条白名单；大尺寸最多六个，一至两个账号展示全部五个槽位，三至四个账号各显示两条，五至六个账号各显示一条。省略项显示数量，完整白名单通过查询入口查看。

## 升级与兼容

标准文件为 `PO0-Firewall.yaml` 和 `po0-firewall.js`。本目录及 `scripts/po0/relay/egern/` 的旧文件名仅用于兼容，内容必须与标准文件同步；旧模块更新后同样使用新脚本。更新主配置后刷新模块；已有桌面组件若仍绑定旧名称，重新选择“PO0 防火墙状态”。

本机存储键、账号和槽位保留兼容，旧操作名称仍可识别。首次升级会备份旧配置，清除后同步参数不会自动恢复账号。模块只使用现行防火墙接口，先查询，缺少覆盖才写入；同/24网段共用记录，写入被拒绝时仅复查一次。

历史SSH/自建功能见[固定归档](https://github.com/SchweppesSoda/VPS-Toolkit/releases/tag/archive/po0-full-20260907.1)。专项检查：`node tools/po0/test-egern-official-report.mjs`。项目说明见[PO0 README](../../../relay/README.md)。
