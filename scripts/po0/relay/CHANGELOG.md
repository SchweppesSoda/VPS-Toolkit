# PO0 变更记录

## Egern 20260909-ssid-guard-v1

- 修复 Widget 刷新、上报状态和部分立即上报入口绕过 SSID 跳过的问题；普通入口命中后一律不请求、不加白。
- 保留上次官方结果和检查周期，显示明确跳过提示；只有显式手动强制上报可绕过，只读查询仍不加白。
- 使用真实 ctx.script.name 形态补齐各入口回归，并验证首次运行、实时参数变更及 SSID 不可用行为。

## Egern 20260908-official-widget-v4

- 白名单统一按槽位编号升序排列，自动记录放在最后；当前网段保留绿色标记，不再置顶。
- 小组件摘要、完整白名单与只读查询使用同一排序，不改变官方返回数据或上报行为。

## Egern 20260908-official-widget-v3

- 移除底部弹性空白，按尺寸和账号数量放大文字，将剩余高度分配给账号及白名单内容。
- 大尺寸双账号改为并排卡片，各自逐槽位换行展示完整白名单；多账号按容量逐条展示并提示省略数量。
- 小尺寸单账号补充上报时间，中尺寸单账号补充白名单；只读查询也逐条换行，未知槽位不显示为未占用。

## Egern 20260908-official-widget-v2

- 官方小组件恢复完整状态层次：出口与网络摘要、账号结果、槽位和占用；大尺寸展示各账号出口、上报时间，少量账号展开白名单或错误原因。
- 小尺寸保留槽位与占用，多账号提示省略数量；底部时间使用最近检查，未知名额不再显示为 0/0。
- 更新模块脚本缓存版本，标准入口与历史兼容副本同步。

## 2026.09.08+build.1 / OpenWrt 2026.09.08-r1

- manager 精简为转发管理，保留 NAT/SNAT/MSS、BBR、诊断、备份与鉴权更新；迁移检查阻止静默移除仍在使用的保护。
- LAN Worker 精简为固定脚本更新镜像，保留现有 HTTP 配对和服务入口；原官方账号显式迁移至同机官方客户端。
- Windows、macOS、Linux、OpenWrt、Egern、Stash、Loon 只保留官方上报；清理自建界面、请求引擎和旧任务，迁移保留账号、槽位、名称、停用选择与网络行为。
- Stash 首页使用只读缓存 Tile；Egern 小组件全部空间用于官方状态；Loon 管理页移除自建入口。
- 旧接收器、DDNS、WebAuth、来源学习、iplist/ipdb 构建与任务退出主线。协议回归保留最小旧对端测试夹具。
